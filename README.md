# BigWigs for Raven

Package: stock **BigWigs** + raid modules + **BigWigs_Raven** · Interface **11402**

## About

Stock BigWigs for Classic Era, plus the **BigWigs_Raven** plugin (Raven raid content / 1.18-oriented timers).

## Status — not a final release

This is **not a finished, bug-free product**. Timers and encounter modules may be incomplete.

## Bugs / feedback

If you find a problem, open an **Issue** in this repository: instance/boss, addon versions, steps, screenshot/log.

## Install

Copy **all** folders from this package into `_classic_era_\Interface\AddOns`, then `/reload`.
